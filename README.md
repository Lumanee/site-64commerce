# Site 64 Commerce (maquette)

Site statique (HTML, CSS, JavaScript), sans outil de compilation. Ouvrez `index.html` dans un navigateur pour le voir.

- `index.html` : toutes les pages (accueil, offres, fiche, vendre, agence, actualités, contact)
- `logo-64commerce.png` : logo
- `connexion-logiciel.md` : comment les annonces seront publiées depuis le logiciel

Les annonces, l'équipe et les chiffres sont fictifs.
